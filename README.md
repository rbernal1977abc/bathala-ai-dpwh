# BATHALA Intelligence - DPWH AI Governance Platform

## Overview
AI-powered governance system for the Department of Public Works and Highways (DPWH) Philippines to prevent corruption, ensure transparency, and improve project oversight.

## Features
- **AI-Powered Contractor Vetting**: Real-time background checks and risk assessment
- **Document Analysis**: AI processing of SEC, PCAB, and financial documents
- **Project Monitoring**: Real-time oversight of construction projects
- **Dual AI Agents**: Agent 1 (Deep Analysis) and Agent 2 (Fast Verification)
- **Mobile-First Design**: Fully responsive for mobile browsers
- **Real Data Integration**: Connects to government databases (SEC, PCAB, PhilGEPS, COA)

## Technology Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (Mobile-first)
- **Backend**: Node.js, Express.js
- **AI Integration**: DeepSeek (Agent 1), Grok (Agent 2)
- **File Processing**: PDF parsing, OCR, document verification
- **Deployment**: Vercel (Serverless)
